# pr-triage-workshop

Sandbox for the live pull request triage workshop demo.

## Quickstart

Install the dependencies and start the demo service:

```bash
npm install
npm run demo -- --port 3000
```

Then open your browser at `http://localhost:3000` to see the demo dashboard.

## Structure

- `src/` – demo service source code
- `test/` – unit tests

## Contributing

Open a pull request against `main` and wait for a review before merging.
